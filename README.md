# Words Rush Game
A simple game where you join a session and answer the question in the givin time!

# How to run



## Download the Whisper Language package

  1- Go to https://huggingface.co/ggerganov/whisper.cpp and download a model.

  2- Reference the model in the appsettings in the `ModelPath`

### Build the solution
In Terminal make sure that you are in the solution folder and run `dotnet build`


### Start the server
In Terminal navigate to the Server folder and run `dotnet run` to start the server.

### Start the client
In Terminal navigate to the Client folder and run `dotnet run` to start the Client.
